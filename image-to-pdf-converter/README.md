# 이미지를 PDF로 변환

간단하고 빠른 이미지-PDF 변환 웹 애플리케이션입니다. 브라우저에서 바로 실행되며, 별도의 서버나 설치가 필요 없습니다.

## 기능

- **드래그 앤 드롭**: 이미지 파일을 드래그하여 간편하게 업로드
- **다중 이미지 지원**: 여러 이미지를 한 번에 PDF로 변환
- **실시간 미리보기**: 업로드한 이미지를 바로 확인
- **이미지 관리**: 개별 이미지 삭제 가능
- **자동 크기 조정**: 이미지가 PDF 페이지에 자동으로 맞춰짐
- **반응형 디자인**: 모바일, 태블릿, 데스크톱 모두 지원
- **완전 클라이언트 사이드**: 이미지가 서버로 전송되지 않음 (개인정보 보호)

## 지원 포맷

- JPG / JPEG
- PNG
- GIF
- WEBP
- 기타 대부분의 이미지 포맷

## 사용 방법

### 로컬에서 실행

1. `index.html` 파일을 브라우저로 엽니다
2. 이미지를 드래그하여 업로드 영역에 드롭하거나, 영역을 클릭하여 파일을 선택합니다
3. 여러 이미지를 추가할 수 있습니다
4. "PDF로 변환 및 다운로드" 버튼을 클릭합니다
5. PDF 파일이 자동으로 다운로드됩니다

### 웹 호스팅

간단하게 무료로 배포할 수 있습니다:

#### Netlify (추천)

1. [Netlify](https://netlify.com)에 로그인
2. 드래그 앤 드롭으로 `image-to-pdf-converter` 폴더를 업로드
3. 완료! 바로 사용 가능한 URL이 생성됩니다

#### GitHub Pages

1. GitHub 저장소 생성
2. `image-to-pdf-converter` 폴더 내용을 푸시
3. Settings > Pages에서 활성화
4. `https://yourusername.github.io/repository-name` 에서 접근

#### Vercel

1. [Vercel](https://vercel.com)에 로그인
2. "New Project" 클릭
3. `image-to-pdf-converter` 폴더를 임포트
4. 배포!

## 기술 스택

- **HTML5**: 구조
- **CSS3**: 스타일링 (그라디언트, 애니메이션)
- **Vanilla JavaScript**: 기능 구현
- **jsPDF**: PDF 생성 라이브러리 (CDN)

## 문제 해결

### PDF가 다운로드되지 않아요
- 브라우저의 팝업 차단을 해제해주세요
- 다른 브라우저에서 시도해보세요

### 이미지가 업로드되지 않아요
- 파일이 이미지 포맷인지 확인해주세요
- 파일 크기가 너무 크지 않은지 확인해주세요

### 변환이 느려요
- 이미지 개수가 많거나 파일 크기가 큰 경우 시간이 걸릴 수 있습니다
- 고해상도 이미지는 변환 전에 리사이즈하는 것을 권장합니다
